**Jupyter notebooks and Python scripts from the Advanced IT Skills and Japanese Language Program run by Plus W with the Pakistan Japan Centre. They cover Python programming, data analysis, data visualization and machine learning with pandas, NumPy, Matplotlib, seaborn, scikit-learn, NLTK and Streamlit.**

Each class folder has the lecture code and my assignment for that week, so you can follow the course from Python basics to working ML models.

## What's inside

| Folder | Topics | Highlights |
| --- | --- | --- |
| [Class-2](Class-2) | Python fundamentals | Lecture code and assignment notebooks |
| [Class-3](Class-3) | Python fundamentals, continued | Lecture code and assignment notebooks |

## Skills covered

- **Python:** data types, control flow, functions, file I/O
- **Data wrangling:** pandas, NumPy, CSV, JSON, SQLite
- **Data visualization:** Matplotlib, seaborn
- **Machine learning:** linear regression, train/test splits, preprocessing and evaluation with scikit-learn
- **NLP:** text cleaning, stop words and stemming with NLTK for spam classification
- **Apps:** interactive prediction demos with Streamlit

## Run the notebooks

```bash
git clone https://github.com/Clufy/python-data-science-ml-course-assignments.git
cd python-data-science-ml-course-assignments
pip install jupyter pandas numpy matplotlib seaborn scikit-learn nltk streamlit
jupyter notebook
```

To launch a Streamlit demo from Class 7, for example the churn predictor:

```bash
streamlit run Class-7/customer_churner_prediction.py
```
